# 群组协作与右侧工作区

> 设计与实现分开：本文保留模块目标；当前实现、已知反例见 [状态矩阵](status.md)。实施顺序统一遵循 [整改计划](../tasks/plan.md)，局部成功不等于全部约束通过。

本轮验收目标：群组是一条共享消息流和可追踪任务队列，成员由真实模型响应；右侧能使用浏览器及渲染交付物。

## 群组约定

- 用户、成员的群消息持久保存；同群所有成员下一次响应时读取同一条群历史，私聊不自动注入。
- 用户 @姓名 定向唤醒，@所有人 广播到全部专业成员；未 @ 时交给所选成员/协调人。UI 提供成员提及与全员入口，不能将一个下拉菜单视为完整群聊。
- 成员通过群消息工具发言和 @；协调人通过分工工具为一位、多位或全体成员派任务。每项有接收回执、排队、执行、完成/失败/停止状态以及负责成员，结果回到群里。
- 被派任务的成员用真实模型理解目标、查看最新群历史并实际执行/回复。多个目标逐个执行，减少当前共用文件和浏览器并发冲突，但后台子进程仍可能打破串行假设；这是执行顺序，不是屏蔽成员消息。
- 人类执行中可以继续追加同会话任务，进入人工 FIFO 优先队列；其他会话请求暂不并入当前任务且保留草稿；停止可中止当前模型、直接工具进程与队列；后台/detached 完整回收尚未通过。人工追加尚不是当前任务实时纠正。重启不自动重放副作用，未完成项标记中断，明确展示。
- 分工路由使用当前群组、准确成员姓名或本轮短编号；长 ID 仍兼容，但不要求模型抄写 UUID。群设置可修改名称、目标和成员列表；执行中禁止调整名单以免改变待执行任务归属。
- 成员提交 completed/blocked 结果回执；只有响应但没有回执时标“已回复 · 结果待确认”，成员不自动视为完成；E01 已将根状态按成员回执汇总，完整交付证据仍另行验收。
- 同一轮自动唤醒设 40 次上限，重复投递去重，已排队成员结合最新群消息一次处理，避免通知重复派工；防止 @ 往返无限循环；达到上限明确报错，不伪装完成。成员与群的归属由宿主校验，委派不跨空间扩权。
- 分工工具负责实际派发，不能只在文本里宣称“已让全员接单”。成员普通最终回复中的有效 @ 也会路由。完成阶段协调人收到一次汇总任务，基于真实结果回应用户。

## 右侧工作区

- 浏览器工具栏：地址栏、前进、后退、刷新/停止加载，显示当前 URL 和加载错误；用户可主动导航。共享当前空间专用浏览器，不导入个人浏览器资料。
- 产物支持“预览 / 源码”，源码一键复制；HTML 使用无 App IPC、无同源权限的隔离 frame 渲染，允许页内脚本交互，但不允许读本机或打开弹窗。源码按原文复制，不复制预览注入内容。
- 本地直接引用的 CSS、JS 和图片通过授权沙盒读取后嵌入，不直接开放 file://。Markdown 渲染基本标题、段落、列表、代码块；图片直接显示；其他文本保留可读展示。预览错误有明确提示，不能把源代码当成已渲染网页。
- 浏览器与产物切换、抽屉、尺寸变更和设置弹窗不会让原生网页遮住界面按钮。

## 验证

真实模型验证 @定向响应、共享消息、协调人派发两名成员各自收到并交付、汇总，消息/任务跨重启保存。纯基础测试验证路由隔离、去重、停止与上限。实际 Electron 验证 HTML 渲染/源码/复制、隔离不可调用 App API，以及本地网站导航/前进/后退/刷新；不复制生产对话或执行真实平台发布。

## 当前实测与剩余边界

已通过真实模型两名专业成员的独立交付与协调汇总，以及 @全员、执行中补充指令和停止当前 Bash/模型与队列。执行目前串行；不是后台并行多电脑。重启保留消息和任务终态，中断任务不自动重放。

HTML 支持内联交互及直接引用的本地 CSS/JS/图片。外部脚本、联网请求、嵌套资源依赖、完整 ES module 工程、PDF/Office 和媒体预览没有完整支持，不把静态网页验收等同任意 Web 应用运行。Markdown 当前为基本块级渲染。历史消息保存在数据库，界面/模型仅取有限近期上下文；全文检索、分页和长历史摘要仍待补。自动长期计划、精细并发控制、跨进程恢复与平台发布继续按原里程碑推进。
