# 三栏工作台

> 设计与实现分开：本文保留模块目标；当前实现、已知反例见 [状态矩阵](status.md)。实施顺序统一遵循 [整改计划](../tasks/plan.md)，局部成功不等于全部约束通过。

需求 R16/R17：缺模型或空间时显示首次配置；齐备后直接进入工作台。设置在单独入口打开，错误不退回引导。已有凭据及授权不迁移、不删除。

左栏持久 Bot/群组列表、新建和职责编辑。群组包含现存 Bot，指定成员响应。消息按工作空间及会话隔离；群组上下文不注入成员私聊。当前串行任务；E01 拒绝其他会话请求隐式并入同一根任务且保留草稿，E06 再处理独立生命周期。

中栏显示用户消息、成员回复和真实工具事件；再次发消息包含本会话有限历史。SQLite 保存角色、会话、消息、任务归属和产物。崩溃标中断，不自动重放。

右栏用主窗口 WebContentsView 嵌入隔离浏览器，执行浏览器动作自动展开；网页没有 App IPC。浏览器页面在任务完成后保留。产物点击通过主进程校验已登记任务、空间授权，再经现有沙盒读取。文本作为 textContent、图片为数据 URI，HTML 不在主页面执行。暂不支持的格式明确提示。

左右栏独立收放，分隔线可拖拽及方向键调整。宽度、收放与选中会话持久保存。原生浏览器边界跟随右栏容器，收起/预览/设置弹窗时隐藏，避免覆盖操作区。

验收：首次配置→工作台，重启直达；Bot/群组与会话隔离；左右开关与宽度持久；真实模型浏览器自动展开且仅一个主窗口，生成文件点击预览；重启复用配置及授权。自动建队、群组委派、图像生成与复杂文档渲染继续按原任务实施。

## Bot 通过任务创建团队

修复目标：用户要求创建五名成员及群组时，模型调用 create_team 工具；宿主在当前授权空间内以 SQLite 事务保存成员身份、职责、群组和协调人，左栏自动更新，不能只输出文档。协调人固定为发起本次任务的 Bot，五名专业成员计入群组人数，协调人单独记录且可在群组响应。工具不接受任意工作空间、凭据或权限字段，新成员复用空间基础授权和当前应用模型配置。相同协调人和群名称重复调用返回已创建团队；成员名单冲突明确失败，不创建半个团队或默默覆盖职责。模型可 list_team 查询已存团队。自动调度已有局部实测，依赖/审批和可靠恢复仍待整改。

连接状态采用实际模型 ID：请求发出前显示“正在连接 {model}…”，收到 SDK 内容块或非空 assistant/message 后显示“{model} 已连接”；连接失败不得显示已连接。不再使用“真实模型”作为产品文案。
