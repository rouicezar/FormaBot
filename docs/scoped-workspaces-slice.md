# 轻量产物栏、独立设置与固定项目空间

## 最新确认的需求与设计

用户已接受首发固定项目：Bot / 群组只在创建时绑定文件夹。换项目创建新的 Bot / 群组，保留旧会话；不提供中途换目录并清空记忆。未另选目录时固定到创建当时的默认目录，修改默认只影响以后创建。旧记录无独立目录时归原工作台目录，不能随默认改变迁移。

会话名册与执行路径分离，保留模型、历史、记忆和产物。私聊任务使用 Bot 绑定空间，群任务使用群空间；任务保存实际执行路径，历史预览用原路径权限。原生用户选择器加授权取得目录，网页/模型不能提交任意路径。后端拒绝修改已有绑定，不能只隐藏前端按钮。每次工具调用仍由执行层限制文件、命令、浏览器和子进程。

设置采用单实例独立 BrowserWindow，模型、默认空间、审批、记忆、隐藏会话多标签，IPC 来源与功能白名单限制。右侧只保留文件名、小图标和悬停提示；聊天产物用小型蓝色文件图标与紧凑链接。

## 验收

类型与存储测试；创建绑定、默认变化不迁移旧项目、拒绝篡改和修改、授权取消/拒绝、群目录优先、重启保持；原生设置独立窗口及键盘、多种宽度、时间轴/聊天双入口、复制源码。真实工具权限反例与真实模型另列，构造 UI 不冒称模型验收。目录授权不等于对外发布/部署授权。

状态：实现与回归进行中，尚未交用户手测。完整需求与阶段门禁见 `requirements-review-2026-09-12.md`。

## 用户手测清单

构建 `build/s1a/mac-arm64/FormaBot.app`，版本 0.1.0，最终提交和包内 dist 摘要见 `build/s1a/build-info.json`。退出旧版再打开；本片未更改真实用户配置、聊天或授权数据。

1. 打开已有产物回复：正文提到已登记文件的标题、文件名或路径时，应直接显示蓝色圆角文件图标链接，点击在右侧打开；正文已引用者不再重复挂在下方，未提及者紧凑列在末尾。
2. 右侧只显示小型图标与文件标题，悬停可辨识功能与完整路径；复制在标题右端，预览/源码可切换；在窄窗口复测。
3. 点设置：独立窗口出现，可移动、切换五个标签；重复点设置聚焦同一窗口，关闭后主窗口继续工作。
4. 新建测试 Bot 时另选测试项目文件夹并授权；编辑时空间只读。右键旧 Bot → 基于此 Bot 创建新项目，职责/模型复用，旧聊天保留，新项目无旧项目记录。
5. 改默认文件夹后，已建 Bot / 群空间不变，随后新建才使用新默认。群任务与私聊分别显示群/成员绑定的目录。
6. 重启后模型、项目空间与原记录仍在。正常发送任务并检查实际产物目录；本片未新增云端真实模型执行证据，此步骤仍待产品手测。
