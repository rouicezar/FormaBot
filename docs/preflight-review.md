## 首轮交付界限

1. 最简 App 能打开、配置模型与 Key、选工作空间和产出目录，明确显示待授权/未配置/运行/失败/完成状态。
2. 包内 SDK/Harness 进程能受控启动退出，不读取个人 Harness 配置，不要求终端或下载执行组件。
3. 授权桥接、进程停止和文件/凭据隔离先验证；通过后才用用户在 App 内配置的真实模型开放工具任务。
4. 单成员先跑读取→编辑→Bash→浏览器测试站点→本地产物；随后持续实现文档建队、群内委派、人工介入和生图。首轮单成员通过不等于团队产品完成。

产品边界已足够明确；尚未固定的模型清单、Node 版本、SQLite 驱动、最低系统版本等作为模块实现中的核验项，不再要求用户做技术选型。缺少 API Key 不阻止开发配置界面，也不能以假模型跑任务替代验收。
