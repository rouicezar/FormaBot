# 三栏工作台验收 · 2026-09-09

> 阶段证据：成功用例仅覆盖本文明确场景；后续审查发现的反例仍有效。当前完整验收见 [状态矩阵](../status.md)。

## 实现

首次缺模型/工作空间时进入引导；配置完成进入独立三栏工作台，设置移至入口。生产 userData 继续使用原路径及系统加密身份；没有重置用户凭据、工作空间或授权。

左侧可新建 Bot、定义/编辑职责、新建含现有 Bot 的群组。中央保留按空间/会话隔离的消息，群组选择一个执行成员。右侧 WebContentsView 内嵌真实浏览器，工具执行时自动展开，完成后保留页面；点击 write/edit 登记的交付文件预览文本或图片。左右独立抽屉、鼠标拖拽与方向键调整宽度，重启恢复布局和会话。

## 实测证据

- 类型检查/构建成功；Vitest 8 项通过，含真实 Harness 生命周期、持久授权、配置及工作空间/私聊/群组隔离。
- scripts/smoke-workbench.mjs：真实 Electron 首次配置后进入工作台，新建 Bot/群组、指定成员、两条分隔线拖拽、两侧独立收放、重启和设置密钥不回显通过。测试凭据仅验证存储，未执行模型任务。截图 `.tmp/workbench-ui-SLJ4mT/workbench.png`。
- scripts/test-tools.mjs：真实 read/write/edit/bash，文本/图片预览，HTML 只作为文本，空间外读写及符号链接拒绝、命令环境无模型 Key。
- scripts/live-task.mjs：使用 App 已配置的真实 DeepSeek/deepseek-v4-flash，包内 Harness 执行 read→browser open/read→write→edit→bash。模型读入本地原文，取得本地测试网页验证码，生成报告并修改状态、Bash 验证。断言每个工具成功、实际文件含原文要点、验证码和最终状态。
- 同一真实任务断言只有一个主窗口、右栏自动展开且主窗口有嵌入网页视图；点击对话产物，预览来自真实文件内容。截图 `.tmp/live-workbench-app/task.png`，文件 `.tmp/live-workbench-space/outputs/report.md`。
- 打包 App 重启直接进入工作台，保存模型、空间、完成任务和授权；第二个真实模型任务读取报告，重复授权对话会使测试失败，实测通过。
- scripts/live-group.mjs：通过界面新建“验收编辑”和“报告验收群”，指定成员用真实模型读取报告并按职责回复；新成员复用原空间授权，群组仅有本群两条消息。
- scripts/smoke-package.mjs：实际 .app 从独立目录、最小 PATH 启动，内置 Node/Harness 可用；已有用户配置直接进入工作台。

真实模型测试使用同一 App 加密身份的隔离测试配置副本，仅在仓库 .tmp 下测试空间内操作。没有修改生产用户的模型/目录或替用户授权生产空间；没有真实平台发布行为。

## 剩余边界

群组当前指定一个成员串行执行；自动建队、委派交接、执行中追加指令、生图模型尚未完成。预览当前覆盖已由 write/edit 登记的文本和常见图片，其他格式提示暂不支持；Bash 生成文件的自动发现、复杂文档渲染待补。浏览器上传/下载、弹窗登录和平台发布未开放，不代表完成 T07。当前任务过程事件尚不跨重启保留；消息、交付记录和终态保留。仅真实验证 DeepSeek 一家服务商。macOS arm64 本机开发 .app 未签名公证，干净机器安装仍待验证。
