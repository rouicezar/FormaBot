# 群协作与右侧工作区验收 · 2026-09-09

> 阶段证据：成功用例仅覆盖本文明确场景；后续审查发现的反例仍有效。当前完整验收见 [状态矩阵](../status.md)。

## 结果

共享群消息、定向/全员 @、真实派发队列、成员回执、独立执行交付、协调汇总、执行中补充指令、停止、状态持久化已接入同一个执行流程。成员只读取当前群历史，私聊不默认注入。每个任务仍调用 App 所配置的真实模型；文件与 Bash 继续使用既有授权和执行边界。

右侧增加浏览器地址栏、前进、后退、刷新、停止加载；HTML 预览/源码/复制，支持本地直接引用的样式、脚本和图片；Markdown 基本渲染与图片展示。源码复制来自已登记文件，HTML 在无 App IPC/同源权限的隔离 frame 中运行。

- 类型检查与打包成功，12 项测试通过，包括群路由/身份边界、队列去重与停止、成员名单验证、名字/短编号、结果回执以及既有授权/配置/模型连接状态测试。
- scripts/live-collaboration.mjs：真实 DeepSeek v4-flash，在新建隔离群中 @研究员，仅该成员响应并正确读取群内约定 TEAM-7319；协调人给两名专业成员实际派任务，两人分别读取真实素材（FILE-8642）并各写一份 Markdown。断言文件存在且同时含两个校验码、任务状态 completed、产物挂在实际成员名下；随后协调人汇总。断言不存在因分工通知而重复执行的成员任务。重启后消息、任务状态、交付记录保存。最终证据 .tmp/live-collab-Mmi5lb/collaboration.png。
- scripts/live-group-control.mjs .tmp/live-collab-Kc69o8：真实模型 @所有人 后建立全员队列；实际 Bash sleep 正在执行时，人类仍可追加指令；停止中止当前模型/命令和至少两项等待任务，不重复授权。

- scripts/smoke-workbench.mjs：群设置成员增删、基础 Bot/群组、模型持久化和抽屉/拖拽/重启回归；测试配置与生产隔离。

## 修复过的实测问题

测试空间最初误放在测试凭据目录内，真实执行层正确拒绝读写；测试目录已分离，并以实际文件内容重测。模型会把长期岗位职责当成额外任务，已为明确“只需本人回复”的请求约束后续唤醒。模型抄错 UUID 导致派发失败，改用当前群组、名称或短编号，并返回可纠正错误。已排队对象收到分工后的 @通知会结合共享历史处理，不重复创建同一轮任务。工具派发失败不能由协调人代写文件冒充成员交付，验收检查实际成员队列和产物归属。

未使用生产私人对话做模型验收；生产模型/空间/授权/历史未清空。只测试本地站点，不包含平台发布行为。边界见 docs/group-and-preview-design.md。
