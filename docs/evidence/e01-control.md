# E01：状态与人工队列整改

范围：整改 F05 的根状态误报及 F04 的人工追加倒序、不同会话混入同根任务；不关闭 F04/F05 的全部问题。原始反例保留在设计审查，不把失败观察改成成功证据。

## 变更与用户可见行为

- ConversationSession 返回明确状态，按失败、受阻、待确认、成员报告完成汇总所有工作。主管最后成功汇总不能覆盖下属未确认或失败。
- 私聊和群聊没有 task_result 时均为 responded，持久保存；模型报告 completed 显示“成员报告完成 · 待验收”，不宣称已经完成产品验收。没有新增验收按钮或伪造验收操作。
- 人工任务使用独立 FIFO 优先队列，正常自动工作继续排队，两队列均可标记停止。此举不修改正在运行的 prompt，不能视为即时纠正。
- 不同会话的新指令不能混进已有根任务，拒绝时不创建消息/工作记录并保留输入；发送回包不会清空用户新编辑的内容。未来独立生命周期仍按 E06 实施。
- 不迁移/清空生产配置、授权、成员或对话，不扩大执行权限；完成状态码保留兼容性，但文案明确仅为成员回执。
