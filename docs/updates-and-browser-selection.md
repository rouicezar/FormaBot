# 通用产品补齐：自动更新与浏览器选区

状态：方案，尚未实现。关联需求R28/R29、计划E12/E13；不改变模型和空间一次配置、不重复基础授权的原则。用户提供蓝色圆形下载箭头作为更新提示参考。

## 1. 自动更新：确定采用 electron-updater

当前Electron应用已使用electron-builder；选择与之配套的electron-updater，主进程维护状态，渲染层只显示及发送用户动作。当前 `package.json` 为0.1.0，构建配置为未签名dir，没有更新发布源；现有构建不能被称为已经支持在线更新。

官方说明：macOS自动更新需要代码签名，更新元数据需要zip目标；发布器支持GitHub Releases或HTTPS更新源等方式。[electron-builder自动更新](https://www.electron.build/docs/features/auto-update/)、[macOS构建](https://www.electron.build/mac/)

### 用户流程

设置“关于与更新”显示当前语义版本、构建号、渠道、最近检查时间及“检查更新”。正常状态不展示无意义图标。发现经过校验且适合当前平台/架构的新版本后，在应用工具区显示蓝色圆形下载箭头，悬浮“发现新版本 x.y.z”；图标是全局产品状态，不占群消息。

点击查看版本说明、下载大小及“下载并更新”。下载过程显示进度，可取消；下载完成显示“重启并更新”。无任务执行时可一键安装并重启。执行中可以下载，但安装须等任务完成或由用户选择停止并保存后重启；不能擅自杀掉运行任务、丢草稿或把更新当任务完成。失败保留旧版并提供重试，不把离线说成“已是最新”。

初版默认启动后检查一次、长时间运行最多每日一次；可在设置关闭自动检查。下载和安装由用户点击发起，`autoDownload=false`、不默认退出时安装。应用内明确“可用更新”“下载完成”两种状态，不能用同一图标含混表示。

### 服务与发布

1. 开发侧：唯一bundleId和稳定产品名，SemVer+递增build号；将Harness/运行时/浏览器与App版本固定打包，记录组件清单。先支持当前macOS arm64，其他平台独立验收，不宣称一个包通用。
2. 构建侧：签名、公证、生成dmg+zip及latest-mac.yml/校验摘要；CI中签名凭据加密，不进入源码或客户端。
3. 发布侧：stable/beta分渠道；固定HTTPS来源及发布身份。可使用专用发行仓库或自有HTTPS更新站，源代码仓库无需公开；不可在客户端内嵌私有GitHub访问token。
4. 客户端：限制更新协议/来源、平台、架构、版本与签名；无效元数据/签名/哈希拒绝。支持渠道回退策略但禁止自动降级读写不兼容数据库。
5. 数据侧：程序包与userData/工作空间独立；更新不能清空Key、空间、授权、群组、历史和浏览器登录。迁移在App独占下执行，先备份、检查磁盘和schema兼容，再事务迁移。失败保留可恢复旧数据；旧程序不允许打开已升级且不兼容的schema。
6. 恢复侧：更新前写任务/草稿检查点并停止接收新任务；不确定外发动作进入待核查，升级后不盲目重放。更新包替换和数据库回滚是两个问题，不能承诺OS自动替换包就保证数据回滚。

更新状态：idle → checking → available / up_to_date / error → downloading → downloaded → waiting_for_safe_restart → installing；进度由真实事件驱动。API仅 `getVersion/check/download/install/cancel`，不接受网页传任意下载URL或执行命令。版本说明作为不可信内容安全渲染。

上线前待提供：Apple Developer签名/公证配置、选定的更新托管目标及发布授权。这些不阻塞版本设置页、客户端状态机和本地测试服务开发，但阻塞真实公网一键更新验收。本轮不创建公开仓库、不发布安装包、不索要不必要的Key。

### 验收

用两个实际签名版本N和N+1跑完整下载安装重启；升级前后比对既有模型配置、工作空间授权、群组、聊天、产物和登录状态。测试无更新、断网、断点重试、错误签名/摘要、磁盘不足、任务执行中、迁移失败和回滚。开发更新服务fixture只证明状态机；未取得签名证据不能宣布正式自动更新完成。蓝色图标必须在真实发现可用版本后出现。

## 2. 浏览器区域吸附选择

目标：用户选中网页中的文字、图片或组件，添加到当前对话；模型只处理该范围。选择不是自动执行，更不是授权抓整页。数据通路是 `浏览器选区 → 本地附件快照 → 输入框材料卡 → 用户发送 → 对应模型输入 → 回复/产物`。

### 交互

浏览器工具栏增加“选择内容”图标和中文悬浮提示。开启后鼠标悬停按DOM元素/语义容器吸附，半透明蓝色渐变遮罩、细蓝边框和圆角高亮；点击锁定，旁边出现“添加到对话”。允许在父/子元素之间调整范围；Esc取消；重新点击可改选。

文字采用拖选Range，保留用户实际选中的句段，不把整段父容器内容替代精确文字。图片/组件以元素边界吸附，可手动拖框纠正；文字模式不干扰原有网页输入法和选择。组件范围只包含可见区域，超出视口要提示，不静默滚完整页。

点击“添加到对话”产生带来源网址、文字摘录/裁剪缩略图的材料卡，可删除、检查，添加后不直接发送、不消耗模型。发送时记录目标Bot/群与该附件版本，切换会话不串材料。输入“翻译”默认只翻译卡片正文；图片/组件分析只基于选区，不隐式读取整页。需要额外背景时说明并由用户添加。

### 实现路径和边界

当前浏览器是Electron WebContentsView，不是普通iframe。遮罩必须在浏览器页内的隔离脚本/独立覆盖view绘制，不能指望工作台DOM的z-index盖过它。优先实现受控隔离脚本的命中计算，可信App浮层承载确认按钮；主进程维护pickSessionId和选区记录。

命中基础使用elementFromPoint，精确文字用Selection/Range，图片及复杂组件用capturePage(rect)保存可见像素。顶层elementFromPoint遇到子文档只会返回iframe本身，不能假装能读跨域内部；跨域iframe、closed shadow DOM、canvas等无法可靠抽取时退化为用户拖框裁剪，并明确这是图片材料。[MDN命中](https://developer.mozilla.org/en-US/docs/Web/API/Document/elementFromPoint)、[Selection](https://developer.mozilla.org/en-US/docs/Web/API/Window/getSelection)、[Electron截图](https://www.electronjs.org/docs/latest/api/web-contents#contentscapturepagerect-opts)

执行次序：暂停Bot对当前页面的控制并获取页面租约 → 开启选择 → 固定URL/导航版本/矩形/文本 → 临时移除高亮后截图 → 再校验版本及尺寸 → 本地存储附件 → 用户确认添加 → 释放选择模式。网页跳转、重载、滚动导致选区失效时重新选择；不能把高亮前A区域与导航后B页面混在一个附件。

坐标区分工作台、浏览器view、网页CSS像素和截图像素，验证缩放、Retina、多屏DPR和侧栏拖动；不直接将屏幕像素当CSS坐标。矩形必须裁到view内，禁止抓取其他应用窗口。

BrowserSelection记录：selectionId、kind(text/image/component)、sourceURL/title、capturedAt、navigationId、frameId、rects、text、screenshotAttachmentId、hash、conversationId和用户确认时间。组件只附安全可见文本及截图，不把完整DOM/脚本/隐藏属性发给模型。

主进程校验IPC发送者、frame、会话token、尺寸/字节数和导航状态；网页没有通用文件/模型/执行API。保留sandbox/contextIsolation、关闭nodeIntegration。[Electron安全建议](https://www.electronjs.org/docs/latest/tutorial/security)

密码框/密钥输入不允许抓取；链接去掉凭据及已知敏感参数。选择可能包含业务数据，先让用户在材料卡中看清实际发送内容。输入材料始终标为网页数据，不能因为选中一段“忽略用户指令”就改变角色或授权。不抓Cookie、localStorage或未选中邻接正文。

### 模型与存储

精确文字直接作为文本材料；图片/组件必须真正传递图像内容，而不只是文件路径或URL。按成员modelProfile能力检查图片输入；当前仅加入DeepSeek视觉ID预置，图片传入尚未完成，不能因此宣称能识图。不支持图像的模型明确提示用户选择已配置视觉模型，未经选择不静默换供应商或上传到另一服务。

附件存入应用管理的本地附件区，绑定工作空间/会话可见性；输出仍保存用户指定的产物目录。设置保留/删除策略，删除草稿附件回收无引用文件，删除Bot不误删群中仍被其他消息引用的材料。

### 验收

本地站点提供两段不同文字、图片、表格、组件、canvas、iframe、shadow DOM、输入框和滚动区。逐项检验：只翻译所选一句；图片真实模型识别选区特有标记；组件分析不带邻接诱饵内容；捕获范围无蓝色遮罩；导航失效不混内容；输入框密码不采集；Esc/取消不发送；手动接管时Bot不抢页面；窗口缩放/侧栏调整/DPR变化坐标正确。

跨域/特殊页面以可见裁剪完成需求，原图下载/高精度DOM提取是后续增强，不把降级偷偷改为全页截图。普通页面与降级材料均需用打包App和已配置真实模型验收。
