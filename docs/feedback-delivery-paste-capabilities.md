# 手测反馈：交付状态、截图粘贴与本机工具

用户反馈：普通回复仍需改善；已交付但根显示受阻；截图粘贴无入口；工具安装反复浏览网页。新增澄清：允许App发现本机已安装工具，工作区隔离不能使工具不可见。

## 已核实根因

当前运行plain-language包。所查文章轮次首审实际报告completed+ready，但artifacts同时含md和pl；主进程用preview接口验证交付，pl因不能预览被拒，整份回执未入账。首审最终responded，正式排版被阻断；后续另一通知又新建排版任务完成文件，根保留blocked。不能简单把底部红字改成成功。先分离文件登记和预览能力，并让通知不能另开任务绕过已阻断的正式下游；历史记录不静默重写。

输入框没有paste图片处理；现有图片链只接browser-capture，图片存在本地附件区并随视觉任务发送。新增剪贴板图片附件入口，固定归属粘贴时会话，尺寸/体积校验、缩略图/删除、保留原文字；只发图时默认请求查看图片。失败保留附件，切会话不串图。

工具管理员职责仅是“安装管理扩展/skill/MCP”，固定工具目录无安装或加载工具。实际运行多次浏览器下载失败、尝试/tmp脚本被正确拦截；浏览器被用来绕过缺少下载/安装路径。能力管理文档E11明确未实现。项目https://github.com/cathrynlavery/diagram-design是Skill/插件包；其官方安装方法针对特定宿主，不能把Codex/Claude的插件安装命令在FormaBot里运行就当接入成功。当前不执行用户生产安装任务，不复制该项目为伪安装。

## 当前片实现范围

1. 独立的文件交付检查：在同一沙盒内检查真实路径、文件类型/大小、越界/硬链接，任意扩展名文件可登记；是否支持预览另判断。不放宽工作区或凭据目录边界。
2. blocked正式任务的通知回执保留原任务状态，不通过新通知绕过；新的明确派单/返工仍可创建新链。缺完成回执不冒报完成。
3. 剪贴板图片入口与已有视觉链连接，允许图片加文字或只发图片；普通文字粘贴原样。图片大小限制和失败提示、发送前归属保持。
4. 工具能力如实说明写入宿主提示：当前没有通用Skill/MCP插件加载，安装请求先查官方说明/宿主兼容性，不重复浏览器下载或改写系统插件目录；临时文件使用工作区内目录。

## 本机工具发现与加载方案（用户已授权方向）

- 独立只读宿主发现器：标准应用目录、命令行安装位置、常见Skill/插件目录；仅枚举名称、版本、类型和入口。MCP配置只提取连接类型/命令/参数结构，密钥使用凭据引用，不进入Bot上下文。禁止读取无关文档/浏览器登录数据。
- 可见/兼容/已启用/验证可用分开记录。相同来源和版本去重；发现后不自动执行仓库脚本、不启动全部MCP进程。
- Skill按需读取，保留引用路径；CLI通过受监督适配器调用；MCP经握手和测试后启用；宿主专属插件明确不兼容原因。安装到FormaBot管理目录，保留来源版本和卸载能力，不修改其他宿主插件。
- 必需外部资源按工具授权：例如读取某应用导出文件可选目录；任务执行沿用工作区授权，不开放整个HOME。读取安装目录不等于授权改写它，执行外发动作仍按用户任务和既有权限检查。
- 分片验收：只读发现清单→可用性探测→按需加载Skill→MCP/CLI适配与安装。首次发现范围在UI可见、可停用；默认目录已覆盖的工具无需用户手填路径。该能力需要实际实现，当前不能用提示词冒充。

验证计划：pl登记成功/预览仍可拒绝；缺文件/越界链接拒绝；真实完成准入放行一次，blocked通知不能绕行。打包粘贴图缩略图/删除/归属/文字保持，视觉模型读取合成图。普通回复继续留作原群验收，不宣告已彻底解决。
