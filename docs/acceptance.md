# 产品验收基线

开发阶段验收增加强制用户手测：每个小阶段提供可运行构建、版本标识、改动说明、操作步骤和预期结果；必要自动验证通过后等待用户明确确认。问题修复后重建复测，本阶段未通过不得进入下一阶段。用户手测不代替开发者的执行隔离/故障反例验证，两者均需记录。详见 [开发规则](../AGENTS.md)。

这是通过条件，不是结果清单；当前逐项结果见 [状态矩阵](status.md)。基础测试应使用临时工作空间和自建测试网页；真实平台验证另列结果，禁止把模拟结果当成实测。

| ID | 场景与通过条件 | 关联 |
| --- | --- | --- |
| A01 | 首任务未授权：文件、命令、浏览器操作均未启动；拒绝授权后仍不执行。 | R08 |
| A02 | 一次授权后完成读取、写入、编辑、Bash 和浏览器动作，记录实际结果。 | R06,R09 |
| A03 | 同空间第二任务、新成员、群组委派和重启后继续执行：不出现重复授权。 | R09 |
| A04 | 撤销后旧队列与新任务不继续使用旧授权；新空间不能继承不属于它的授权。 | R09,R10 |
| A05 | 文件绝对路径、..、符号链接、Bash 子进程和浏览器上传下载无法绕过授权范围。 | R10 |
| A06 | 至少两个预置服务商分别用真实 API 执行工具任务；无效 Key 显示可理解错误，日志无密钥。 | R05 |
| A07 | 两个成员完成分工和交接，群里能追踪负责人、状态、产物；成员发起建群可运行。 | R02,R03 |
| A08 | 私聊、群内 @ 和普通群任务正确路由；人类新指令和停止能影响正在运行的任务。 | R04 |
| A09 | 未参与成员不能获得无关私聊、私人记忆或未授权账号；委派不升级能力范围。 | R10 |
| A10 | 用户在测试网页登录，重启后可复用状态；两个身份不串号，账号失效请求登录而非重授工作空间。 | R11 |
| A11 | 用户在 App 将产出目录从默认 outputs 改为空间内另一目录，重启保留，生成文件实际落入该目录，对话预览与打开指向同一真实文件；失败不显示已交付。 | R07 |
| A12 | 同文件写入冲突受控；暂停、崩溃或网络中断后恢复，不重复对外发布。 | R04,R11 |
| A13 | 设计成员使用指定生图服务商/模型真实生成图片；图片可解码、保存至指定产出文件夹并在对话展示。模型调用失败或文件保存失败不得显示成功交付；成员不能自行改用未授权的服务商。 | R12 |
| A14 | 用户在 App 粘贴或选择本地业务文档，核验读取版本，根据文档建立五名专业成员及主管协作群并显示在侧栏，职责、目录、选题批准节点持久保存；重启可恢复、重复请求不重复创建，导入文档不扩大权限。预期见 tests/fixtures/team-from-document/README.md。 | R13 |
| A15 | 在无 Node.js/npm/dsh/浏览器驱动的干净目标机器安装；首次启动断网也能打开配置、选工作空间，不尝试下载执行组件。联网后在 App 填真实模型 Key 并执行 read/write/edit/bash/browser 到本地产物任务。仅断网打开页面不能算执行验收通过。 | R14,R15 |

真实发布验收需另行选择平台及测试账号，取得该操作授权，保留链接或平台回执；点击发布按钮本身不算成功。

## 新增通用产品验收（未实施）

- A23 / R28：设置显示真实版本；有可用更新出现蓝色图标，用户点击完成签名N→N+1下载/安装/重启；无更新/断网/损坏包明确区分；运行任务安全暂停或等待；既有Key、空间、授权、群与聊天不丢，迁移失败可恢复。详细矩阵见[升级设计](updates-and-browser-selection.md)。
- A24 / R29：文字只翻译所选句段；图片/组件有真实图像输入；蓝色吸附高亮和添加材料卡可调整/取消；截图不含高亮、不越选区；DPR/缩放/iframe/导航失效/密码及注入用例正确；Bot不抢人类页面控制。界面截图和模型ID预置都不等于验收。

A07/A08/A17/A18强化：按[后端架构](backend-architecture.md)的真实语义场景重复验证，全员意图不漏送、无关成员不刷屏、职责跨私聊/群聊一致、改岗来源合法、交接与成果有事实依据；依旧逐小片构建手测。
