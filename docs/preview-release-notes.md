# FormaBot development preview

Download the `.dmg` below for macOS on Apple Silicon. Open it and copy FormaBot into Applications. SHA256SUMS.txt verifies the download; SOURCE_COMMIT.txt identifies the exact build.

This is a development preview, not a stable release. It is not Developer ID signed or notarized. macOS may prevent it from opening; do not disable system security protections. Figma remote authorization is currently unresolved. Existing task-control and delivery limitations remain in the release readiness report.
